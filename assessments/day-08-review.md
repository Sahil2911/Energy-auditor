## Score: 4 / 5

```
    Salt dosed  = 0.2 × 2 = 0.4 litres/min      ✓
    Downstream  = 0.005 x = 0.4                 ✓
    x           = 80 litres/min                 ✓
    Water flow  = 80 − 2 = 78 litres/min        ✗ not done
```

`C₁V₁ = C₂V₂` applied cleanly and fast. The 80 litres/min is the **total**
downstream flow, which includes the 2 litres/min of tracer solution dosed in. The
question asks for the **water** flow.

## The finding

**Fully correct arithmetic, answering a question that was not asked.** Not a method
loss — a reading loss. The model answer states it both ways and subtracts in each.

Second occurrence of this shape: on Day 10 the makeup-water *reduction* was
likewise not stated, though both figures were computed.

## Worth noticing

This is an **inverse problem**. An open channel cannot be metered, so a known
tracer is dosed and the dilution measured downstream — measure the effect, infer
the cause. Same structure as Day 7B's flue-gas work, in a different chapter.
